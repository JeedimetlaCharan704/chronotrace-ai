💡 Reusable Practice for Future Projects

Inverted Spec-Driven Verification:

Never let an AI coding agent generate solution code until you have established the reproduction test and failure condition. By writing the test and specifying the exact failing line first, the AI is constrained to a surgical, verifiable fix rather than hallucinating unbounded codebase rewrites.
