ChronoTrace AI — Product Requirements

Complete functional specification for the visual incident archaeology workspace.

🚀 The 5-Step Core Journey

1
Video / Scenario Ingestion

Drop a 15s MP4/WebM screen recording or select one of 3 real-world bug benchmarks.

2
Visual Keyframe Decomposition

Temporal OCR and spatial bounding boxes map cursor trajectory and stuck UI elements.

3
Causality Chain & AST Localization

Pinpoints the exact faulty source file, line number, and AST expression without requiring logs.

4
Reproduction Test Execution

Synthesizes and runs an executable Playwright test script that reliably reproduces the failure.

5
Self-Healing Patch Verification

Displays side-by-side code diff, applies the patch, and re-executes tests with a green pass.

🖥️ Unified 4-Quadrant Workspace Layout

Quadrant 1: Video Scrubber
Synchronized frame-by-frame canvas player with cursor tracking and visual anomaly highlights.
Quadrant 2: AST Root Cause
Interactive causality tree and live code syntax viewer pinpointing the exact defect line.
Quadrant 3: Test Runner
Playwright test synthesizer and live execution terminal with streaming assertion logs.
Quadrant 4: Verified Patch
Surgical unified diff viewer with 1-click test re-run and patch export capabilities.
